# Palette's Journal

## 2025-05-15 - [Two-step Confirmation for High-Risk Actions]
**Learning:** In high-pressure clinical environments (like a resuscitation), accidental interactions with touch-screens are common. Destructive actions like "Reset" must be guarded by a confirmation pattern. Using a time-bound confirmation (e.g., 3-second auto-revert) provides a safety net without adding significant latency to the workflow if the user genuinely intended to reset.
**Action:** Implement two-step confirmation with auto-revert and high-contrast visual cues (like red styling) for destructive or high-risk buttons in clinical tools.

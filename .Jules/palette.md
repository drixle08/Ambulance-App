## 2025-03-24 - High-Stakes Confirmation Pattern
**Learning:** In high-pressure clinical environments (e.g., resuscitation), destructive manual actions (like "Reset") require intentional friction to prevent data loss, but hands-free alternatives (voice commands) should remain frictionless for efficiency.
**Action:** Implement two-step touch confirmations with short auto-revert timeouts (e.g., 3 seconds) and distinct visual cues (red high-contrast states), while allowing voice-triggered events to bypass this UI friction.

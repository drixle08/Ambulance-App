## 2025-05-15 - [Confirmation patterns for clinical tools]
**Learning:** In high-pressure clinical environments like resuscitation, destructive actions (e.g., Reset) should never be a single-tap operation. A two-step confirmation with a clear visual state change and an auto-revert timeout provides a safety buffer without hindering the workflow.
**Action:** Always implement a two-step confirmation for destructive actions in medical tools, using high-contrast visual cues (like red backgrounds) and a 3-second auto-revert timeout.

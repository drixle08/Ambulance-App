## 2025-05-15 - Two-step confirmation for high-risk clinical actions
**Learning:** High-pressure clinical environments (like cardiac arrest) require safeguards against accidental destructive actions (e.g., resetting a timer). A two-step "Confirm?" pattern with a high-contrast visual state (e.g., `bg-red-600`) and an auto-revert timeout (3 seconds) provides a safe yet efficient recovery path.
**Action:** Implement two-step confirmation for reset or delete actions in clinical tools, ensuring the "Confirm" state is visually distinct and temporary.

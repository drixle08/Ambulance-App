## 2025-05-15 - Safety Confirmation Pattern
**Learning:** For destructive clinical actions (like 'Reset') in high-pressure environments, a two-step confirmation pattern with high-contrast visual changes (e.g. red background) and haptic feedback ensures safety without adding excessive friction. A 3-second auto-revert timeout allows the UI to return to its safe default state if the confirmation is not completed.
**Action:** Use the two-step safety confirmation pattern (Confirm? state + 3s timeout + red styling + haptic pulse) for any irreversible or clinical state-clearing actions.

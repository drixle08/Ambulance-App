## 2025-05-15 - [Safety Confirmation Pattern for Destructive Actions]
**Learning:** In high-stress clinical environments (like resuscitation), destructive actions like "Reset" require a two-step confirmation to prevent accidental data loss. A 3-second auto-revert timeout provides a balance between safety and speed.
**Action:** Use the two-step confirmation pattern with haptic feedback (25ms pulse) and a 3-second auto-revert for irreversible or critical UI actions.
